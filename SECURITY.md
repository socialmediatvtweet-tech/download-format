# Security Policy

## Supported Versions

Since this is an active project, security updates are provided for the latest version.

| Version | Supported          |
| ------- | ------------------ |
| latest  | :white_check_mark: |
| < latest| :x:                |

## Reporting a Vulnerability

If you find a security vulnerability in `.download` or the installation script, please report it responsibly:

* **Do not** open a public GitHub issue for security vulnerabilities, as this could expose users before a fix is released.
* Instead, please send an e-mail directly to: **jakubfribl@outlook.com**
* You can expect an initial response within a few days. Once the vulnerability is confirmed, a fix will be prepared and released as soon as possible.
